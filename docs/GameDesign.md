# GameDesign(ゲーム仕様)

ここに書いてあることだけが確定した仕様。未確定の論点は `TODO.md` の「仕様の未決事項」に置き、決まったらこちらへ移す。
大きくなったら章ごとに `docs/design/NN_*.md` へ分け、このファイルは索引(章 → ファイルの表)にする。

## 1章 コンセプト

- 2人のプレイヤーがオンラインで1対1のじゃんけんをするバカゲー。
- お互いの手が常に見えている。掛け声の間に、相手に勝つ形へ自分の手を動かせば勝てる。
- 手はなぞるだけで動かせるが、ゴムのようにつながっていて隣の指までつられる(QWOP風)。急いで作ると崩れ、毎ラウンド変な形から始まる。
- 失敗した手には名前が付いて大きく表示される。失敗の瞬間が一番の見せ場。
- 振り切った失敗(名前付きの手)は反則より強く、手によっては次のラウンドへ効果を残す。

## 2章 じゃんけんのルール

### 2.1 指の状態

- 指は5本(親指・人差し指・中指・薬指・小指)。各指は「曲がり具合」0.0(伸びきり)〜1.0(曲がりきり)を持ち、判定に使う。

| 曲がり具合 | 状態 |
|---|---|
| 0.3 未満 | 伸びている |
| 0.7 超 | 曲がっている |
| それ以外 | 中途半端 |

### 2.2 手の形

5本の指すべてで判定する(失敗した手の名前の種類を増やすため)。

| 形 | 条件 |
|---|---|
| グー | 5本とも曲がっている |
| パー | 5本とも伸びている |
| チョキ | 人差し指と中指が伸び、親指・薬指・小指が曲がっている |
| 名前付きの手 | 中途半端な指が無く、上の3つ以外(2.4節の表の29種類) |
| 反則 | 中途半端な指が1本でもある |

### 2.3 勝敗

- 「ぽん」の瞬間の手の形で判定する。
- 強い順に グー・チョキ・パー > 名前付きの手 > 反則。強さが違えば強い側の勝ち
  (グー・チョキ・パーを狙うのが本筋のまま、失敗にも「振り切った失敗」と「中途半端な失敗」の差を付けるため)。
- グー・チョキ・パーどうしは、グーはチョキに、チョキはパーに、パーはグーに勝つ。同じ手どうしはあいこ。
- 名前付きの手どうし、反則どうしはあいこ。

### 2.4 手の名前

名前付きの手と反則は、形に応じた名前を大きく表示する。名前付きの手は下表の名前そのもの。反則は次の手順で名前を決める。

1. 中途半端な指を、曲がり具合 0.5 以上なら「曲がり」、未満なら「伸び」へ寄せる(名前を引くためだけに使い、勝敗には影響しない)。
2. 寄せた5本の状態で名前を決める。

| 寄せた結果 | 表示 |
|---|---|
| 中途半端な指が無い | 下表の名前 |
| グー・チョキ・パーになる | ほぼ○○(例: ほぼグー) |
| 反則の形になる | ゆるい + 下表の名前(例: ゆるいピストル) |
| 5本とも中途半端 | グニャグニャ |

指の状態(○=伸び、●=曲がり。親・人・中・薬・小の順):

| 状態 | 名前 | 状態 | 名前 |
|---|---|---|---|
| ●○●●● | 指さし | ○●●●● | グッド |
| ●●○●● | 自主規制 | ○○●●● | ピストル |

### 2.5 手の効果

- 「ぽん」の瞬間に下表の名前付きの手を出していたら、勝敗に関係なく効果が発動する。両者が同時に発動することもある。
- 効果は必ず出した側が得をし、相手に掛かる(自分が損をする効果は分かりにくいため)。
- 効果は次のラウンドから掛かる。同じ効果が掛かっている間にもう一度発動したら、残りのラウンド数を長い方に揃える(足さない)。試合が終わったら消える。
- 結果表示で、発動した効果を手の名前のそばに1行で表示する。
- 表に無い名前付きの手は、2.3節の強さだけを持つ(まず8種類で試し、面白ければ広げる)。

| 手 | 効果 | 続くラウンド数 |
|---|---|---|
| 自主規制 | 相手の画面で、自分の手にモザイクが掛かり、2区間目に呼ぶ名前の上に規制テープが貼られる | 1 |
| 強めの自主規制 | 同上 | 2 |
| 親指／人差し指／中指／薬指／小指だけ寝坊 | 相手の同じ指が寝坊し、目標へ動く速さが遅くなる | 1 |
| ピストル | ラウンド開始時、初期配置の後に相手の指をランダムに1本撃ち、曲がりきりにする | 1 |

- モザイクと規制テープは掛け声の間だけ。結果表示では外す(負けた理由が見えるように)。

| 数値 | 初期値 |
|---|---|
| 寝坊した指の動く速さの倍率 | 0.5 |

## 3章 遊ぶ環境

- ブラウザで遊ぶ。PCでもスマホでも遊べる。
- 画面は縦向きのみ。横長のウィンドウでは左右に余白を付けて縦長の画面を中央に表示する。
- 奥(画面上側)に相手の手、手前(画面下側)に自分の手。両者の勝利数と掛け声を表示する。
- 両者の手は指先を相手へ向ける。自分の手は上向きで画面の下から、相手の手は下向きで画面の上から手首が出る(どちらの手か迷わないため)。
- 操作はタッチとドラッグだけで完結する(キーボードを使わない。PCではマウスで同じ操作)。

## 4章 対戦相手の見つけ方

- 次の2つから選べる。
  - **ランダムマッチ**: 待っている人どうしを自動で組み合わせる。
  - **合言葉**: 同じ合言葉を入れた2人が対戦する(知り合いと遊ぶため)。

## 5章 試合の流れ

1. 試合開始。両者0勝。
2. ラウンド開始: 両者の手を初期配置(6.3節)で表示する。
3. 掛け声「さいしょは・(双方の手の名前)・じゃん・けん・ぽん」。この間ずっと操作できる(操作の時間を長くし、手を整える余裕を作るため)。
   - 2区間目に入った瞬間の両者の手の名前を、それぞれの手のそばにその区間の間だけ表示する。中央の掛け声は空にする。
     途中で形を変えても表示は変えない(相手の形を読んで後出しで組み直す読み合いを生むため)。
   - 名前を呼ぶだけで判定はしない。勝利数は変わらない。
4. 掛け声が終わった瞬間(「ぽん」の区間の終わり)に判定する(2章)。結果と両者の手の名前、発動した効果(2.5節)を表示する。
5. 勝った側に1勝。あいこは勝利数を変えない。
6. 結果を表示したまま待ち、どちらかが3勝していれば試合終了。それ以外は 2 へ戻る。
7. 試合終了: 勝敗と最終の勝利数を表示する。「もう一度」で0勝から新しい試合を始める。

| 数値 | 初期値 |
|---|---|
| 勝利に必要な勝ち数 | 3 |
| 掛け声の合計時間 | 5.0秒(さいしょは・(手の名前)・じゃん・けん・ぽん 各1.0秒) |
| 手の名前を呼ぶ区間 | 2区間目 |
| 結果の表示時間 | 2.0秒(失敗した手の名前を読ませるため) |

## 6章 操作

### 6.1 指の操作

- 自分の手の上(画面の手前側)をなぞって指を動かす。
- **左右の位置で指を選ぶ。**手前側を指先の並びで縦の帯に分け、ポインタがいる帯の指を動かす。
  - 親指と小指の帯は画面の端まで広げる。帯の線は描かない(手そのものが目印)。
  - 手は大きく、指先の間を広げて描き、帯の幅をスマホで指先1つ分以上にする(狙った指に触れるようにするため)。
- **上下の位置で曲がり具合を決める。**その指の指先の高さがポインタの高さへ付いてくる
  (指先が動く範囲より上なら伸びきり、下(手のひら・手首)なら曲がりきり)。
- 押したまま横へなぞると、通った指が次々にポインタの高さへそろう。タップでも1本動かせる
  (1回なぞれば手全体を作れるようにし、相手を見て作り替える時間を残すため)。
  - グーは手のひらを横にこする、パーは指先の上を横になでる、チョキは「低・高・高・低・低」と山を描く。
- 押したら、離すまでは手前側の外へ出てもなぞり続ける。
- 同時に触れるのは1か所。スマホの2本目以降のタッチは無視する(PCのマウスと同じ条件で対戦するため)。

### 6.2 操作しづらさ

現実の手の不器用さを誇張する(理不尽さより「自分の手のせいだ」と納得できることを優先するため)。

- **連動**: なぞって指の目標が d 変わると、隣の指の目標も d × 連動の強さ だけ変わる。
  その先の指へも掛け算で伝わる(中指を動かすと薬指は 0.4、小指は 0.4 × 0.5 = 0.2)。
  連動の強さが負なら隣の指は逆向きに動く(親指は他の指と向かい合って動く)。
  どの手(グー・チョキ・パー)にも連動に逆らう境目がちょうど1か所ある(手によって作りやすさに差を付けないため)。
- **ゴムの遅れ**: 触っている指もつられた指も、ばねで目標を追いかけ、勢いで少し行き過ぎてから落ち着く
  (手全体をゴムのように感じさせ、急いで作ると崩れるようにするため)。曲がり具合が 0.0 / 1.0 に当たったらそこで止まる。
- 1回なぞっただけでは、連動に逆らう境目の指が中途半端に残りやすい。往復してこすると整う。

| 慣性の数値 | 初期値 |
|---|---|
| ばね定数 | 120 |
| 減衰 | 12(行き過ぎは約1割) |

| 隣接する指 | 連動の強さ |
|---|---|
| 親指 − 人差し指 | −0.4 |
| 人差し指 − 中指 | 0.4 |
| 中指 − 薬指 | 0.4 |
| 薬指 − 小指 | 0.5 |

### 6.3 初期配置

- ラウンド開始ごとに、各指の曲がり具合を 0.0〜1.0 からランダムに決める。
- 手首の向き・手の位置・大きさは固定する(3章。見づらくなるだけなので)。

## 7章 オンライン対戦

- 判定はサーバーが行う。サーバー時刻の「ぽん」の瞬間に両者の手の形を確定する(クライアントだけで勝敗を確定させない)。
- 画面に見える相手の手は通信遅延の分(約0.1秒)遅れている。直前に変えたのに負けることがあるのは仕様として受け入れる。

## 8章 見た目と演出

- 絵(手・背景・UI)はコードで描く。判定・操作には影響しない見た目だけの演出。

### 8.1 手

- 太い輪郭線のマンガ風。角丸の手のひらと手首、指先の爪。指は付け根を手のひらの下に隠す。
- 指はゴムホースのように柔らかく描く。動くと指の途中が遅れてしなり、揺れが残る。止まっていても少しうねる。
- 曲がるほど指が短くなり、爪が隠れる(曲がりきりで付け根のこぶだけ残る)。
- 中途半端な指はプルプル震えて赤みがかる(反則の原因がひと目で分かるため)。伸び・曲がりの範囲に入った瞬間、指先に小さな火花が出る。
- 触っている指は縁が光り、ポインタの方へ少し傾く(見た目だけ。判定・操作には使わない)。
- 袖の色で両者を分ける(自分は暖色、相手は青系)。

### 8.2 掛け声

- 区間が変わるたびに掛け声の文字が弾んで出て、両者の手が拍に合わせて小さく弾む(じゃんけんで拳を振るリズム)。
- 掛け声のそばに区間の数だけランプを並べ、いまの区間まで点ける(「ぽん」までの残りが分かるように)。

### 8.3 ぽんと結果

- 判定の瞬間、画面が白く光って揺れ、集中線が出て、両者の手が相手へ突き出る。
- 結果の文字(かち!/まけ…/あいこ)と手の名前はハンコのように大きく押す(名前付き・反則の名前が一番目立つように)。
- 勝った手は跳ね、負けた手はしぼんで暗くなる。あいこは両方が小さく揺れる。

### 8.4 画面

- 背景は上(相手側)を青系、下(自分側)を暖色系に分ける。
- 勝利数は星で表す(勝利に必要な数だけ並べ、取った分を点ける)。
