# GameDesign

1対1のオンラインじゃんけん。相手の手は丸見えなのに、自分の手が思い通りに動かないバカゲー。

## 1章 コンセプト

- お互いの手が常に見えている。掛け声の間に、相手に勝つ形へ自分の手を動かせば勝てる
- ただし手は操作しづらく(QWOP風)、毎ラウンド変な形から始まる
- 失敗した手には名前が付いて大きく表示される。失敗の瞬間が一番の見せ場
- 操作はタッチとドラッグだけで完結する(スマホ前提。PCではマウスで同じ操作)

## 2章 画面構成

- 縦長画面
- 奥(画面上側)に相手の手、手前(画面下側)に自分の手
- 両者の勝利数と掛け声を画面に表示する

## 3章 操作

### 3.1 指の操作

- 指は5本(親指・人差し指・中指・薬指・小指)。各指は「曲がり具合」0.0(伸びきり)〜1.0(曲がりきり)を持つ
- 指の上でドラッグする。指先方向へドラッグすると伸び、手のひら方向へドラッグすると曲がる
- ドラッグ方向は手首の回転に追従する(手が逆さなら、画面上の上下も逆になる)
- 操作できるのは掛け声の間だけ

### 3.2 操作しづらさ

現実の手の不器用さを誇張する。理不尽さより「自分の手のせいだ」と納得できることを優先するため。

- **連動**: 動かした指につられて隣の指も動く(薬指は中指・小指に特につられる)
- **慣性**: 指を離すと少し行き過ぎたり、戻ったりする

| 隣接する指 | 連動の強さ(初期値) |
|---|---|
| 親指 − 人差し指 | 0.2 |
| 人差し指 − 中指 | 0.4 |
| 中指 − 薬指 | 0.6 |
| 薬指 − 小指 | 0.5 |

### 3.3 初期配置

- ラウンド開始ごとに、各指の曲がり具合を 0.0〜1.0 から、手首の回転を 0〜360° からランダムに決める
- 手の位置と大きさは固定する(見づらくなるだけなので)

## 4章 判定

### 4.1 指の状態

| 曲がり具合 | 状態 |
|---|---|
| 0.3 未満 | 伸びている |
| 0.7 超 | 曲がっている |
| それ以外 | 中途半端 |

### 4.2 手の形

親指は判定に含めない(厳しすぎると誰も成立させられないため)。人差し指・中指・薬指・小指の4本で判定する。

| 形 | 条件 |
|---|---|
| グー | 4本とも曲がっている |
| パー | 4本とも伸びている |
| チョキ | 人差し指と中指が伸び、薬指と小指が曲がっている |
| 反則 | 上記以外(中途半端な指が1本でもあれば反則) |

### 4.3 勝敗

- 「ぽん」の瞬間の手の形で判定する
- 片方だけ反則 → 反則した側の負け
- 両方反則 → あいこ
- グー・チョキ・パー同士は通常のじゃんけん

### 4.4 反則した手の名前

反則になった手は形に応じた名前を大きく表示する。4本の指の状態(○=伸び、●=曲がり)で引く。

| 人 | 中 | 薬 | 小 | 名前 |
|---|---|---|---|---|
| ○ | ● | ● | ● | 指さし |
| ● | ○ | ● | ● | 自主規制 |
| ● | ● | ○ | ● | 結婚指輪アピール |
| ● | ● | ● | ○ | 指切りげんまん |
| ○ | ● | ● | ○ | メロイック |
| ● | ○ | ○ | ● | ねじれチョキ |
| ● | ● | ○ | ○ | 下手なチョキ |
| ○ | ● | ○ | ● | とびとびチョキ |
| ● | ○ | ● | ○ | ひねくれ者 |
| ○ | ○ | ○ | ● | スリー |
| ● | ○ | ○ | ○ | OKのなりそこない |
| ○ | ● | ○ | ○ | 中指だけ寝坊 |
| ○ | ○ | ● | ○ | 薬指だけ寝坊 |

中途半端な指が1本でもある場合は「グニャグニャ」と表示する。

## 5章 試合の流れ

1. 試合開始。両者0勝
2. ラウンド開始: 両者の手を初期配置(3.3節)で表示する
3. 掛け声「じゃん・けん・ぽん」(合計約3秒)。この間だけ操作できる
4. 「ぽん」で判定(4章)。結果と反則の名前を表示する
5. 勝った側に1勝。あいこは勝利数を変えない
6. どちらかが3勝したら試合終了。それまで 2 へ戻る

| 数値 | 初期値 |
|---|---|
| 勝利に必要な勝ち数 | 3 |
| 掛け声の合計時間 | 3.0秒(じゃん・けん・ぽん 各1.0秒) |

## 6章 オンライン対戦

- 判定はサーバーが行う。サーバー時刻の「ぽん」の瞬間に、両者の手の形を確定する(クライアントだけで勝敗を確定させない)
- 画面に見える相手の手は通信遅延の分(約0.1秒)遅れている。直前に変えたのに負けることがあるのは仕様として受け入れる
- マッチング方法: 未定
