# GameDesign(ゲーム仕様)

ここに書いてあることだけが確定した仕様。未確定の論点は `TODO.md` の「仕様の未決事項」に置き、決まったらこちらへ移す。
大きくなったら章ごとに `docs/design/NN_*.md` へ分け、このファイルは索引(章 → ファイルの表)にする。

## 1章 コンセプト

- 2人のプレイヤーがオンラインで1対1のじゃんけんをするゲーム。

## 2章 じゃんけんのルール

- 手はグー・チョキ・パーの3種類。
- グーはチョキに、チョキはパーに、パーはグーに勝つ。同じ手どうしはあいこ。
- 両者の手が出そろうまで、相手の手は見えない(後出しを成立させないため)。

## 3章 遊ぶ環境

- ブラウザで遊ぶ。PCでもスマホでも遊べる(縦横どちらの画面でも操作できるようにする)。

## 4章 対戦相手の見つけ方

- 次の2つから選べる。
  - **ランダムマッチ**: 待っている人どうしを自動で組み合わせる。
  - **合言葉**: 同じ合言葉を入れた2人が対戦する(知り合いと遊ぶため)。
