## 1章 コンセプト

- 2人のプレイヤーがオンラインで1対1のじゃんけんをするバカゲー。
- お互いの手が常に見えている。掛け声の間に、相手に勝つ形へ自分の手を動かせば勝てる。
- ただし手は操作しづらく(QWOP風)、毎ラウンド変な形から始まる。
- 失敗した手には名前が付いて大きく表示される。失敗の瞬間が一番の見せ場。

## 2章 じゃんけんのルール

### 2.1 指の状態

- 指は5本(親指・人差し指・中指・薬指・小指)。各指は「曲がり具合」0.0(伸びきり)〜1.0(曲がりきり)を持つ。

| 曲がり具合 | 状態 |
|---|---|
| 0.3 未満 | 伸びている |
| 0.7 超 | 曲がっている |
| それ以外 | 中途半端 |

### 2.2 手の形

5本の指すべてで判定する(失敗した手の名前の種類を増やすため)。

| 形 | 条件 |
|---|---|
| グー | 5本とも曲がっている |
| パー | 5本とも伸びている |
| チョキ | 人差し指と中指が伸び、親指・薬指・小指が曲がっている |
| 反則 | 上記以外(中途半端な指が1本でもあれば反則) |

### 2.3 勝敗

- 「ぽん」の瞬間の手の形で判定する。
- グーはチョキに、チョキはパーに、パーはグーに勝つ。同じ手どうしはあいこ。
- 片方だけ反則 → 反則した側の負け。両方反則 → あいこ。

### 2.4 反則した手の名前

反則になった手は形に応じた名前を大きく表示する。

1. 中途半端な指を、曲がり具合 0.5 以上なら「曲がり」、未満なら「伸び」へ寄せる(名前を引くためだけに使い、勝敗には影響しない)。
2. 寄せた5本の状態で名前を決める。

| 寄せた結果 | 表示 |
|---|---|
| 中途半端な指が無い | 下表の名前 |
| グー・チョキ・パーになる | ほぼ○○(例: ほぼグー) |
| 反則の形になる | ゆるい + 下表の名前(例: ゆるいピストル) |
| 5本とも中途半端 | グニャグニャ |

指の状態(○=伸び、●=曲がり。親・人・中・薬・小の順):

| 状態 | 名前 | 状態 | 名前 |

## 3章 遊ぶ環境

- ブラウザで遊ぶ。PCでもスマホでも遊べる。
- 画面は縦向きのみ。横長のウィンドウでは左右に余白を付けて縦長の画面を中央に表示する。
- 奥(画面上側)に相手の手、手前(画面下側)に自分の手。両者の勝利数と掛け声を表示する。
- 操作はタッチとドラッグだけで完結する(キーボードを使わない。PCではマウスで同じ操作)。

## 4章 対戦相手の見つけ方

- 次の2つから選べる。
  - **ランダムマッチ**: 待っている人どうしを自動で組み合わせる。
  - **合言葉**: 同じ合言葉を入れた2人が対戦する(知り合いと遊ぶため)。

## 5章 試合の流れ

1. 試合開始。両者0勝。
2. ラウンド開始: 両者の手を初期配置(6.3節)で表示する。
3. 掛け声「さいしょは・(双方の手の名前)・じゃん・けん・ぽん」。この間ずっと操作できる(操作の時間を長くし、手を整える余裕を作るため)。
   - 2区間目に入った瞬間の両者の手の名前(反則なら反則名)を、それぞれの手のそばにその区間の間だけ表示する。中央の掛け声は空にする。
     途中で形を変えても表示は変えない(相手の形を読んで後出しで組み直す読み合いを生むため)。
   - 名前を呼ぶだけで判定はしない。勝利数は変わらない。
4. 掛け声が終わった瞬間(「ぽん」の区間の終わり)に判定する(2章)。結果と両者の手の名前(反則ならその名前)を表示する。
5. 勝った側に1勝。あいこは勝利数を変えない。
6. 結果を表示したまま待ち、どちらかが3勝していれば試合終了。それ以外は 2 へ戻る。
7. 試合終了: 勝敗と最終の勝利数を表示する。「もう一度」で0勝から新しい試合を始める。

| 数値 | 初期値 |
|---|---|
| 勝利に必要な勝ち数 | 3 |
| 掛け声の合計時間 | 5.0秒(さいしょは・(手の名前)・じゃん・けん・ぽん 各1.0秒) |
| 手の名前を呼ぶ区間 | 2区間目 |
| 結果の表示時間 | 2.0秒(失敗した手の名前を読ませるため) |

## 6章 操作

### 6.1 指の操作

- 指の上でドラッグする。指先方向へドラッグすると伸び、手のひら方向へドラッグすると曲がる。
- 指の長さ分ドラッグすると曲がり具合が 0→1 変わる。
- ドラッグ方向は手首の回転に追従する(手が逆さなら、画面上の上下も逆になる)。

### 6.2 操作しづらさ

現実の手の不器用さを誇張する(理不尽さより「自分の手のせいだ」と納得できることを優先するため)。

- **連動**: 指を動かして曲がり具合の目標が d 変わると、隣の指の目標も d × 連動の強さ だけ変わる。
  その先の指へも掛け算で伝わる(中指を動かすと薬指は 0.4、小指は 0.4 × 0.5 = 0.2)。
  連動の強さが負なら隣の指は逆向きに動く(親指は他の指と向かい合って動く)。
  どの手(グー・チョキ・パー)にも連動に逆らう境目がちょうど1か所ある(手によって作りやすさに差を付けないため)。
- **慣性**: ドラッグで動くのは各指の「目標の曲がり具合」で、指はばねで目標を追いかける。
  勢いで行き過ぎてから目標へ戻る。曲がり具合が 0.0 / 1.0 の端に当たったらそこで止まる。

| 慣性の数値 | 初期値 |
|---|---|
| ばね定数 | 120 |
| 減衰 | 12(行き過ぎは約1割) |

| 隣接する指 | 連動の強さ(初期値) |
|---|---|
| 親指 − 人差し指 | −0.4 |
| 人差し指 − 中指 | 0.4 |
| 中指 − 薬指 | 0.4 |
| 薬指 − 小指 | 0.5 |

### 6.3 初期配置

- ラウンド開始ごとに、各指の曲がり具合を 0.0〜1.0 から、手首の回転を 0〜360° からランダムに決める。
- 手首の回転はラウンド中は変えない。手の位置と大きさも固定する(見づらくなるだけなので)。

## 7章 オンライン対戦

- 判定はサーバーが行う。サーバー時刻の「ぽん」の瞬間に両者の手の形を確定する(クライアントだけで勝敗を確定させない)。
- 画面に見える相手の手は通信遅延の分(約0.1秒)遅れている。直前に変えたのに負けることがあるのは仕様として受け入れる。
