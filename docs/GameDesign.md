# GameDesign(ゲーム仕様)

ここに書いてあることだけが確定した仕様。未確定の論点は `TODO.md` の「仕様の未決事項」に置き、決まったらこちらへ移す。
大きくなったら章ごとに `docs/design/NN_*.md` へ分け、このファイルは索引(章 → ファイルの表)にする。

## 1章 コンセプト

- 2人のプレイヤーがオンラインで1対1のじゃんけんをするバカゲー。
- お互いの手が常に見えている。掛け声の間に、相手に勝つ形へ自分の手を動かせば勝てる。
- 指はつかんで引いた分だけ曲がり、離した長さで止まる。下へ引ききれば曲がり、上へ押し上げきれば伸び。慌てると引き足りずに中途半端な指が残ったり、隣の指をつかんだりする。毎ラウンド変な形から始まる。
- 5本の指で作れる32通りの形すべてに名前がある。勝ち条件を持つのは本家のグー・チョキ・パーだけで、それぞれ系統(伸びた指の本数)まるごとに勝つ。
  名前付きの手は名前が付くだけで、何にも勝てない。
- 慣れて速くなるほど、面白さは「ぽんの直前に相手を見て、それに勝つ手へ組み替える読み合い」へ移る(組み替える本数が多いほど間に合わない)。
- 中途半端な指が残った手は反則で、必ず負ける。変な名前が付いて大きく表示される。失敗の瞬間が一番の見せ場。

## 2章 じゃんけんのルール

### 2.1 指の状態

- 指は5本(親指・人差し指・中指・薬指・小指)。各指は曲がり具合 0.0(伸びきり)〜1.0(曲がりきり)を持ち、判定では次の3つに分ける
  (まっすぐに見える指だけが伸び、ほぼ握った指だけが曲がりになり、見た目どおりに読めるようにするため)。

| 曲がり具合 | 状態 |
|---|---|
| 0.2 未満 | 伸び |
| 0.8 超 | 曲がり |
| それ以外 | 中途半端 |

### 2.2 手の形

5本の指すべてで判定する(名前の種類を増やすため)。

| 形 | 条件 |
|---|---|
| 反則 | 中途半端な指が1本でもある |
| グー | 5本とも曲がっている |
| パー | 5本とも伸びている |
| チョキ | 人差し指と中指が伸び、親指・薬指・小指が曲がっている |
| 名前付きの手 | 上の4つ以外(2.4節の表の29種類) |

- グー・チョキ・パーをまとめて**本家**と呼ぶ。
- 反則でない手は、伸びた指の本数で**系統**に分かれる(本数を数えるだけで、相手の手がどの系統か分かるようにするため)。

| 系統 | 伸びた指の本数 | 本家 |
|---|---|---|
| グー系 | 0〜1本 | グー |
| チョキ系 | 2〜3本 | チョキ |
| パー系 | 4〜5本 | パー |

### 2.3 勝敗

- 「ぽん」の瞬間の手の形で判定する。
- 反則は、反則でない手すべてに負ける。反則どうしはあいこ。
- 本家は下表の**勝ち条件**を1つ持つ。名前付きの手は勝ち条件を持たず、何にも勝てない(ルールを本家だけで分かるようにするため)。
- **片方だけが勝ち条件を満たせば、その側の勝ち。**両方とも満たす、またはどちらも満たさなければあいこ
  (どの2つの手の組み合わせも、表を引かずに1つのルールで決まるようにするため)。

| 手 | 状態(○=伸び、●=曲がり) | 勝ち条件 |
|---|---|---|
| グー | ●●●●● | 相手がチョキ系 |
| チョキ | ●○○●● | 相手がパー系 |
| パー | ○○○○○ | 相手がグー系 |

### 2.4 手の名前

名前付きの手は、下表の名前を大きく表示する。

指の状態(○=伸び、●=曲がり。親・人・中・薬・小の順):

| 状態 | 名前 | 状態 | 名前 |
|---|---|---|---|
| ●○●●● | 指さし | ○●●●● | グッド |
| ●●○●● | 自主規制 | ○○●●● | ピストル |
| ●●●○● | 結婚指輪アピール | ○●○●● | 強めの自主規制 |
| ●●●●○ | 指切りげんまん | ○●●○● | 結婚指輪見せびらかし |
| ●○●●○ | メロイック | ○●●●○ | アロハ |
| ●●○○● | ねじれチョキ | ○○●●○ | アイラブユー |
| ●●●○○ | 下手なチョキ | ○○○●● | ドイツ式の3 |
| ●○●○● | とびとびチョキ | ○●○○● | ねじれチョキ改 |
| ●●○●○ | ひねくれ者 | ○●●○○ | 下手なチョキ改 |
| ●○○○● | スリー | ○○●○● | とびとびチョキ改 |
| ●●○○○ | OKのなりそこない | ○●○●○ | ひねくれ者改 |
| ●○●○○ | 中指が反抗期 | ○○○○● | 小指だけ寝坊 |
| ●○○●○ | 薬指が反抗期 | ○○○●○ | 薬指だけ寝坊 |

反則も形に合わせた名前を表示する。中途半端な指を、曲がり具合0.5以上なら曲がり、未満なら伸びとみなして決める(名前のためだけで、勝敗には使わない)。

| みなした結果 | 表示 |
|---|---|
| 本家 | ほぼ + 名前(例: ほぼグー) |
| 名前付きの手 | ゆるい + 名前(例: ゆるいピストル) |
| 5本とも中途半端 | グニャグニャ |

## 3章 遊ぶ環境

- ブラウザで遊ぶ。PCでもスマホでも遊べる。
- 画面は縦向きのみ。横長のウィンドウでは左右に余白を付けて縦長の画面を中央に表示する。
- 奥(画面上側)に相手の手、手前(画面下側)に自分の手。両者の勝利数と掛け声を表示する。
- 両者の手は指先を相手へ向ける。自分の手は上向きで画面の下から、相手の手は下向きで画面の上から手首が出る(どちらの手か迷わないため)。
- 操作はタッチとドラッグだけで完結する(キーボードを使わない。PCではマウスで同じ操作)。

## 4章 対戦相手の見つけ方

- 次の2つから選べる。
  - **ランダムマッチ**: 待っている人どうしを自動で組み合わせる。
  - **合言葉**: 同じ合言葉を入れた2人が対戦する(知り合いと遊ぶため)。

## 5章 試合の流れ

1. 試合開始。両者0勝。
2. ラウンド開始: 両者の手を初期配置(6.3節)で表示する。
3. 掛け声「さいしょは・(双方の手の名前)・じゃん・けん・ぽん」。この間ずっと操作できる(操作の時間を長くし、手を整える余裕を作るため)。
   - 2区間目に入った瞬間の両者の手の名前を、それぞれの手のそばにその区間の間だけ表示する。中央の掛け声は空にする。
     途中で形を変えても表示は変えない(相手の形を読んで後出しで組み直す読み合いを生むため)。
   - 名前を呼ぶだけで判定はしない。勝利数は変わらない。
   - これとは別に、掛け声の間ずっと、両者の手のそばに**いまの手の名前と勝ち条件**を小さく表示する
     (例: ピストル・勝ち条件なし、ゆるいピストル・反則)。相手の手が何に勝つかを見て組み替えられるようにするため。
4. 掛け声が終わった瞬間(「ぽん」の区間の終わり)に判定する(2章)。結果と両者の手の名前を表示する。
5. 勝った側に1勝。あいこは勝利数を変えない。
6. 結果を表示したまま待ち、どちらかが3勝していれば試合終了。それ以外は 2 へ戻る。
7. 試合終了: 勝敗と最終の勝利数を表示する。「もう一度」で0勝から新しい試合を始める。

| 数値 | 初期値 |
|---|---|
| 勝利に必要な勝ち数 | 3 |
| 掛け声の合計時間 | 5.0秒(さいしょは・(手の名前)・じゃん・けん・ぽん 各1.0秒) |
| 手の名前を呼ぶ区間 | 2区間目 |
| 結果の表示時間 | 2.0秒(失敗した手の名前を読ませるため) |

## 6章 操作

### 6.1 指の操作

- 自分の手の上(画面の手前側)で、**指をつかんで上下に引っぱって**反転する(触った指を動かしたい方へ引くだけで分かるようにするため)。
- **押した位置に一番近い指をつかむ。**近さは、いま見えている指(付け根から指先までの線)との距離で測る
  (曲がって短くなった指も、見えている所を押せばつかめるようにするため)。指から離れた所を押しても一番近い指をつかむ。
  - 手は大きく、指先の間を広げて描き、指どうしの間をスマホで指先1つ分以上にする(狙った指に触れるようにするため)。
- **押した瞬間につかむ。**つかんだ指は光り、ポインタの上下に付いて伸び縮みする。
- **引いた分だけ曲がり具合が変わる。**下へ引くと曲がり、上へ押し上げると伸びる。伸びきり・曲がりきりの先では止まる。
- **離した長さで止まる**(ばねで伸びきり・曲がりきりへ戻さない)。引き足りずに離すと中途半端な指が残る。
- **1回つかむと1本。**つかんだまま横へ動かしても別の指へは移らない。手前側の外へ出ても続ける。
- 同時に触れるのは1か所。スマホの2本目以降のタッチは無視する(PCのマウスと同じ条件で対戦するため)。

| 数値 | 初期値 |
|---|---|
| 伸びきりから曲がりきりまでの引く距離 | 基準解像度で160px(中途半端の幅は、このうち96px) |

### 6.2 操作しづらさ

- 1本ごとに、つかんで引ききる手間と時間が掛かる。慌てると引き足りずに中途半端な指が残ったり、隣の指をつかんだりする
  (崩れる原因が自分の手だと分かるようにするため)。
- 作った手から組み替えるときは本数に差が出る(グーとチョキの間2本、チョキとパーの間3本、グーとパーの間5本)。
  1本ずつ動かす以上避けられず、「間に合いにくい組み替え」も読み合いの材料にする。

### 6.3 初期配置

- ラウンド開始ごとに、各指を半々の確率で伸びきりか曲がりきりにする(中途半端からは始めない)。
- 手首の向き・手の位置・大きさは固定する(3章。見づらくなるだけなので)。

## 7章 オンライン対戦

- 判定はサーバーが行う。サーバー時刻の「ぽん」の瞬間に両者の手の形を確定する(クライアントだけで勝敗を確定させない)。
- 画面に見える相手の手は通信遅延の分(約0.1秒)遅れている。直前に変えたのに負けることがあるのは仕様として受け入れる。

## 8章 見た目と演出

- 絵(手・背景・UI)はコードで描く。判定・操作には影響しない見た目だけの演出。

### 8.1 手

- 太い輪郭線のマンガ風。角丸の手のひらと手首、指先の爪。指は付け根を手のひらの下に隠す。
- 指は太い管で描く。止まっている指は動かさない(相手の指が変わったかを一目で見分けるため)。
- 曲がるほど指が短くなり、爪が隠れる(曲がりきりで付け根のこぶだけ残る)。
- 伸び・中途半端・曲がりの境を越えた瞬間、指先に小さな火花が出る。
- 中途半端な指は指全体の色を変える(自分にも相手にも一目で分かるように)。
- つかんでいる指は縁が光り、ポインタに付いて伸び縮みする。離すとその長さで止まる。つかんでいない指が動くときは、ばねで少し行き過ぎてから落ち着く(見た目だけ)。
- 袖の色で両者を分ける(自分は暖色、相手は青系)。

### 8.2 掛け声

- 区間が変わるたびに掛け声の文字が弾んで出て、両者の手が拍に合わせて小さく弾む(じゃんけんで拳を振るリズム)。
- 掛け声のそばに区間の数だけランプを並べ、いまの区間まで点ける(「ぽん」までの残りが分かるように)。

### 8.3 ぽんと結果

- 判定の瞬間、画面が白く光って揺れ、集中線が出て、両者の手が相手へ突き出る。
- 結果の文字(かち!/まけ…/あいこ)と手の名前はハンコのように大きく押す(名前付きの手の名前が一番目立つように)。
- 勝った手は跳ね、負けた手はしぼんで暗くなる。あいこは両方が小さく揺れる。

### 8.4 画面

- 背景は上(相手側)を青系、下(自分側)を暖色系に分ける。
- 勝利数は星で表す(勝利に必要な数だけ並べ、取った分を点ける)。
